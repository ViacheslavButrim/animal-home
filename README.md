📖 Про проєкт
«Хатинка лапок» — навчальний front-end проєкт, реалізований у межах курсу Full-Stack Developer.

Проєкт являє собою вебзастосунок, створений для допомоги тваринам у пошуку нової домівки та інформування користувачів про можливості підтримки. Сайт демонструє сучасні підходи до верстки, JavaScript-розробки та організації клієнтської логіки.

✨ Реалізовано:

адаптивний інтерфейс;
інтерактивні компоненти;
динамічну взаємодію з даними;
командну роботу з Git та GitHub.

🎯 Основні завдання проєкту

розробка зручного та адаптивного користувацького інтерфейсу;
реалізація інтерактивних елементів (слайдери, кнопки керування, пагінація, форми);
отримання, обробка та відображення даних із серверної частини;
використання модульного підходу в JavaScript;
відпрацювання навичок командної роботи з Git і GitHub;
застосування сучасних front-end технологій на практиці.
🛠 Використані технології

🔹 Основні
HTML5 — семантична розмітка
CSS3 — стилізація та адаптивна верстка
JavaScript (ES6+) — логіка та інтерактивність

🔹 Інструменти та бібліотеки:

команда термінала для інсталяції бібліотек:
npm install swiper axios accordion-js izitoast sweetalert2 swagger-ui-dist css-star-rating

Коротко що встановиться:
Vite — збірка проєкту та локальний dev-сервер
swiper.js — реалізація слайдерів
axios — робота з HTTP-запитами
accordion-js — розгортані інформаційні блоки
CSS Star Rating — компонент рейтингу
iziToast — система сповіщень
sweetalert2 - це JavaScript-бібліотека для красивих модальних вікон та алертів
swagger — тестування та документація бекенд-запитів
Git / GitHub — контроль версій і командна робота
🚀 Запуск проєкту локально

1️⃣ Клонувати репозиторій:

git clone https://github.com/ViacheslavButrim/animal-home
2️⃣ Перейти в папку проєкту:

cd animal-home
3️⃣ Встановити залежності:

npm install
4️⃣ Запустити локальний сервер:

npm run dev
✨ Зроблено з любов'ю до тварин та Front-End ✨
